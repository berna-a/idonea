

## Idônea Mediação Imobiliária — Real Estate Website

### Brand & Design
- **Dark theme** matching business card: black/dark gray background, white text, gold accents
- Logo uploaded from provided image, used in header and footer
- Professional, clean layout with elegant typography
- Fully responsive (mobile-first)

### Pages & Structure

**1. Landing Page (Single-page with sections)**
- **Header**: Logo + navigation + language toggle (PT/EN) + WhatsApp floating button
- **Hero**: Full-width with property imagery background, headline stating who it's for and what problem it solves, subheadline building trust
- **Pain Points Section**: 3 industry-specific pain points (cards with icons)
- **How It Works**: Step-by-step process (3-4 steps)
- **Investment Section**: 
  - PT version: Helping emigrants invest in their country + foreign investors
  - EN version: Helping international investors find opportunities in Cape Verde
- **Featured Properties**: Grid of sample listings (pulled from database when backend is ready)
- **Social Proof**: Testimonial placeholders with space for real reviews
- **Contact Section**: Contact form (name, email, phone, message, property interest) + WhatsApp direct link + business details from card
- **Footer**: Logo, social links (Instagram, LinkedIn, Facebook), contact info, copyright

**2. Properties Page**
- Filterable property grid (buy/rent, location by island, type, price range)
- Property cards showing image, type, location, price, key specs (bedrooms, bathrooms, etc.)
- Property detail view with image gallery, full description, specs, location, and contact CTA

**3. Language Toggle (PT ↔ EN)**
- Context-based translations stored in a language file
- Toggle in header switches all copy instantly
- Default language: Portuguese

### Backend (Lovable Cloud / Supabase)
- **Properties table**: title, description, type (sale/rent), price, location/island, bedrooms, bathrooms, images, featured flag, status
- **Contact submissions table**: name, email, phone, message, property of interest
- Admin-friendly: properties can be added/managed via Supabase dashboard initially

### Copy Approach
- Portuguese as primary language, professional but plain
- No hype or buzzwords — confident, direct, trustworthy tone
- Short sentences throughout
- EN copy positions Cape Verde as an investment opportunity for international buyers
